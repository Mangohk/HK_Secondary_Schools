資料來源與說明

  • 學校名單、地址、電話、網址、分區與座標主要參考教育局「學校位置及資料」開放數據（日間本地中學；不含特殊、國際、英基及夜校）。
  • 「民間參考組別」主要參考第三方網站 大考 BigExam（dse.bigexam.hk）以文憑試表現等估算的中學組別，並非教育局官方評級；未有可靠對應的學校顯示「未知／不適用」。收生組別每年不同，請自行向學校／教育局核實。

  • 地圖使用 Leaflet + OpenStreetMap 圖磚，無需付費 API 金鑰。

技術說明
  • 本分頁於執行時讀取 data/events.json（單一資料來源）。請以 GitHub Pages 或本機 HTTP 開啟；直接雙擊 index.html 時瀏覽器通常無法 fetch 本地 JSON。
  • 可用狀態、組別、分區、學校篩選；四者以 AND 併用。組別與分區依 schools 對應「學校資料」的民間參考 Band 與行政區（校名須完全相同）；多校事件只要其中一校符合即顯示。指定分區時不顯示空 schools 的項目。選「全港／教育局」只顯示空 schools 的項目；該類項目在組別不是「全部」時不會出現。
  • 時間顯示為香港時間（UTC+8）。可用網址開啟本分頁，例如 ?tab=events&status=官方確認&band=1&school=校名。參數會還原 + 與百分號編碼（含再編碼一次的連結）。
