升中項目說明

  • 本分頁於執行時讀取 data/events.json（單一資料來源）。請以 GitHub Pages 或本機 HTTP 開啟；直接雙擊 index.html 時瀏覽器通常無法 fetch 本地 JSON。
  • 可用狀態、組別、學校篩選；三者以 AND 併用。組別依 schools 對應「學校資料」的民間參考 Band；多校事件只要其中一校符合即顯示。全區／教育局項目（空 schools）僅在組別為「全部」時出現。
  • 事件日期以學校／教育局官網為準；標示「暫定（坊間）」者未經官方確認。時間顯示為香港時間（UTC+8）。
