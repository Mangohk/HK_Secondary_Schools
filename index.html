資料來源與說明

  • 學校名單、地址、電話、網址、分區與座標主要參考教育局「學校位置及資料」開放數據（日間本地中學；不含特殊、國際、英基及夜校）。
  • 「民間參考組別」主要參考第三方網站 大考 BigExam（dse.bigexam.hk）以文憑試表現等估算的中學組別，並非教育局官方評級；未有可靠對應的學校顯示「未知／不適用」。收生組別每年不同，請自行向學校／教育局核實。
  • 地圖座標取自教育局公開地理資料，精確至社區／鄰里層級，可能與校門實際位置略有偏差。
  • 地圖使用 Leaflet + OpenStreetMap 圖磚，無需付費 API 金鑰。

技術說明
  • 本分頁於執行時讀取 data/events.json（單一資料來源）。請以 GitHub Pages 或本機 HTTP 開啟；直接雙擊 index.html 時瀏覽器通常無法 fetch 本地 JSON。
  • 分區、類型、民間組別、只看關注與搜尋跟「學校資料」「地圖與距離」共用同一組條件，切換分頁後仍然有效。本分頁沒有類型或搜尋列。民間組別（按相關學校）寫入共用民間組別；「只看關注」寫入共用關注篩選，只按相關學校是否在關注清單篩選。分區選單寫入共用分區。狀態、指定學校，以及「顯示教育局／全港項目」只影響升中項目。指定學校下拉只列出當前共用篩選交集內的學校（與「學校資料」同一套條件）；交集為空時下拉停用。若已選學校跌出交集會重置為「全部」。有相關學校的項目以 AND 併用各條件。空 schools 的教育局／全港項目只受「顯示教育局／全港項目」控制。
  • 共用條件依 schools 的校名（須完全相同）對應「學校資料」的行政區、類型、民間參考 Band、關注清單與可搜尋欄位。多校事件要有同一所學校同時符合已啟用的分區、類型、組別、只看關注與搜尋。空 schools 的教育局／全港項目只跟「顯示教育局／全港項目」：開關開着就會顯示，關掉就全部隱藏。分區、類型、民間組別、只看關注、搜尋、狀態同指定學校都唔會隱藏呢啲項目。
  • 「顯示教育局／全港項目」預設開着，用來顯示或隱藏沒有相關學校（空 schools）的教育局／全港項目。關掉之後這些項目全部隱藏，並且唔會改共用分區。分區、類型、民間組別、只看關注、搜尋、狀態同指定學校都唔會隱藏呢啲項目。分區選單同學校下拉都沒有「全港／教育局」。
  • 時間顯示為香港時間（UTC+8）。可用網址開啟本分頁，例如 ?tab=events&status=官方確認&band=1&school=校名。band 套用共用民間組別。舊連結 school=全港／教育局 不再單獨收起有學校的項目。參數會還原 + 與百分號編碼（含再編碼一次的連結）。狀態按鈕只剩全部、官方確認、暫定，而且只作用於未過項目。已過項目（狀態為已過，或香港結束日已過）預設隱藏；清單頂端「另有 N 項已過 · 顯示」可按開始日期插回原位。舊連結 status=已過 會展開已過項目，不再當成狀態篩選。
